# Ringside

A ring of shortcuts around your pointer, for macOS and Windows: hold a mouse button, a key or
tap the trackpad, flick toward an action, let go.

This repository holds Ringside's releases. Download the latest from
[Releases](https://github.com/ramgoutam/ringside-releases/releases/latest):

- **macOS** (Apple Silicon): `Ringside-<version>-arm64.dmg`
- **Windows** (64-bit): `Ringside-Setup-<version>.exe`

Once installed, Ringside checks here for new versions, downloads them in the background and
installs them when it restarts. You can also check from Settings › General, or from the menu
bar or tray icon.

Ringside isn't signed by Apple or Microsoft yet, so the first time you open it:

- **macOS:** if it says it can't check the app, open System Settings › Privacy & Security and
  click **Open Anyway**.
- **Windows:** if SmartScreen appears, click **More info › Run anyway**.
